## Release announcement draft

We are excited to share the first public release of CrucibleAgentPlatform.

CrucibleAgentPlatform is a secure control plane for packaging, deploying, scheduling, and operating AI agents across local and containerized runtimes. It includes a FastAPI backend, a React operator console, structured logging and audit visibility, daemon and scheduled execution support, and built-in Model Context Protocol integration for tools, resources, and prompts.

Highlights in this release:

- local and container-based agent execution
- package registration and watcher-driven deployment flow
- scheduled and daemon runtime support
- secrets handling and operational observability
- MCP server integration with frontend visibility for tools, resources, and prompts
- sample agents for common integration patterns

If you try it out, feedback and contributions are welcome.
